## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/Aswini-ox/aswini-developer-portfolio.git
```

Navigate into the project:

```bash
cd aswini-developer-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## 🏗️ Production Build

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```

---

## 🚀 Deployment

This project is designed to be deployed using **Vercel**.

### Deployment flow

```text
GitHub
   ↓
Vercel
   ↓
Production Build
   ↓
Live Portfolio
```

Every new GitHub push can automatically trigger a new deployment when the repository is connected to Vercel.
